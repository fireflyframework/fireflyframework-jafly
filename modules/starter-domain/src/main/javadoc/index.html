Jafly domain starter

org.fireflyframework:fireflyframework-starter-domain assembles the dependencies and shared resources for a domain-layer service. It contains no Java API types of its own. Commands, queries, coordination engines, and clients are supplied by its included components.

Add the starter

After adopting the Jafly parent or importing its BOM, declare:

<dependency>
    <groupId>org.fireflyframework</groupId>
    <artifactId>fireflyframework-starter-domain</artifactId>
</dependency>

Build the domain behavior

Your application supplies its commands, handlers, business rules, and compensating actions. Select and configure the infrastructure the service uses; the dependency bundle does not establish a distributed transaction.
